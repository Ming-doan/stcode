Good to know

A few things before you start.

What do I need?

Python 3.10 or newer, a terminal, and API credentials for a supported model provider. The installation guide covers uv, pip, and running from source.

Can I choose what the agent is allowed to do?

Yes. Start with the default suggest mode to review edits and command execution, or use plan mode to explore before changing files. Choose an approval mode →

Where does my data go?

The agent works in the local or remote workspace you choose. Your configured model provider receives the context needed for the task. Connected tools may send data to their services. Tracing is optional, and recording conversation content is off by default. Review tracing options →

What does it cost?

stcode is open source under Apache-2.0. Model providers and connected services may charge for usage under your accounts. Use /token to review model usage in a session.

Can I return to a task later?

Yes. Use /sessions to reopen a saved conversation. The background service can keep working when you leave the terminal, while actions needing approval require a connected client. Learn about sessions →
